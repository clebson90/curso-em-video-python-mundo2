# 🐍 Curso em Vídeo Python — Mundo 2

Repositório criado para armazenar os exercícios e desafios concluídos no **Mundo 2** do curso de **Python** do **Curso em Vídeo** (Prof. Gustavo Guanabara).

---

## 📌 Sobre o Repositório

Este repositório é focado em estruturas de controle em Python, avançando no domínio de tomadas de decisão complexas e laços de repetição.

---

## 📚 Conteúdos e Tópicos Abordados

- **Condições Aninhadas:** Estruturas condicionais avançadas com `if`, `elif` e `else`.
- **Estrutura de Repetição `for`:** Laços iterativos com contagem e intervalos determinados.
- **Estrutura de Repetição `while`:** Laços condicionais, interrupção com `break` e sinalizadores (flags).

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** [Python 3](https://www.python.org/)
- **Ambiente de Desenvolvimento:** VS Code

---

## 🚀 Como Executar os Códigos Localmente

### Pré-requisitos
Você precisa ter o **Python 3.x** instalado em sua máquina.

**Acesse a pasta do repositório:**
